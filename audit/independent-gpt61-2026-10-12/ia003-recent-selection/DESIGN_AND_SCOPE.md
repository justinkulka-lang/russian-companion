## Deterministic selection rule (assignment schema2, Unit3)

First run all existing taught-owner/prerequisite/teaching/demonstration/independent-membership guards. For each eligible candidate, consider only positive, unambiguous accepted-order prescribed attempts from actual CHECK steps, with matching objective, governed schema, item/unit/rule identities, valid option and a correct flag consistent with the current answer key. Exact pre-policy unit identities accepted by the existing governed matcher remain legitimate; unverified/stale rows do not. Optional practice, guided practice, bare correct IDs, unordered rows and due-review answers do not affect ranking. No wall-clock timestamps or random IDs affect ranking.

Use the latest accepted attempt per candidate. Candidates whose latest valid answer is wrong come first, newest wrong first. Otherwise prefer the least recently answered candidate, with no qualifying history before sequenced history. Ties use authored candidate-list position. A later correct answer resolves an older miss. This is an allocation preference, not demonstration/credit. Once persisted, the assignment is immutable: reopen, remediation, later attempts, restart and restore return the exact same slots. Old v1 completion proofs keep their accepted answer snapshot.
